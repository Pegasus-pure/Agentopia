## Agentopia 实际训练方法

[原论文](https://arxiv.org/html/2606.07513v1)使用现成 Qwen3.5-397B-A17B 作为主要角色与环境模型，Gemini 3 Flash 处理无效输出后的回退。通过 life reward 筛选模拟轨迹后微调 Qwen3.5-397B-A17B，再与未微调基线比较。

因此不能把 Agentopia 描述为“先训练最强教师，再教小模型”。用现成强模型生成五角色数据、再微调较小模型，是本项目可能选择的迁移方案，不是对原实验的逐项复现。部署到 16 GB 显卡的具体模型、量化方式、上下文与训练硬件仍需实测。

## 与米哈游路线的关系

用户希望借鉴《星布谷地》的角色体验。当前找到的资料是[GameLook 演讲整理稿的转载](https://www.yeyulingfeng.com/a/1094488.html)，包含分享者对共用模型与 Agent 架构、记忆传播、多教师在线蒸馏和分级混合奖励的直接陈述。本轮未找到完整官方代码、训练配方或可复现实验，不能声称复现米哈游技术。

可借鉴的工程问题：同模型如何区分角色、各角色何时获知某事、多人场景里如何接话、行为能否改变世界、如何综合评价性格和逻辑。当前采用的可见事件隔离与多维评估是本项目设计，并非其内部实现的已证实细节。

## 当前验证范围

离线测试覆盖五人身份、事件与私聊隔离、同地点对话、重启恢复、失败回滚、并发状态冲突、样本审核与模拟/模型记录隔离。它们验证程序行为；不能证明五位像原作、长期记忆有效、训练有收益或端到端模型服务可用。

## 2026-10-22 实际验证

- 16 项离线测试通过；独立 CLI 离线演练完成三轮，私有暗号未出现在其他角色的可见记录中，模拟数据导出为空。
- 使用已有 gcloud 登录，直接在 Vertex AI 调用 `gemini-2.5-flash`；没有启动 VM 或 GPU，没有复制服务器凭证，没有改动上游核心代码。
- 成功完成一条多栋私聊，以及五角色一个行动轮次。五个角色均返回有效结构化行动，数据库中有六条待审模型轨迹。
- 成功的五角色轮次共报告 2,578 tokens；私聊报告 359 tokens。这不是本轮所有请求的计费总量：此前有一轮因情绪字段格式不符合要求失败，未记录其完整 token 用量。
- 初次真实请求暴露出仅用自然语言约束 JSON 字段不够稳，已加入 Vertex `responseSchema`，并验证失败时整轮不提交。
- 实际输出中，多栋、厘普和秀珍都提议出门，小河和张田中选择移动到院子。这只证明链路可运行；三人的表达较接近，尚不能证明人格足够鲜明。
- 所有样本保持 pending，没有批准为训练集，也没有启动微调。
